# MarbleERP Frontend

Next.js 15 frontend for the MarbleERP inventory and warehouse Phase 1.

## Setup

```powershell
Copy-Item .env.example .env.local
npm install
npm run dev
```

Default frontend URL: `http://localhost:3000`

Default API URL: `http://localhost:4000/api/v1`

The backend seed account is `admin@marbleerp.local` with password `Password123!` once PostgreSQL is running and the backend seed is executed.
